# GitHub Pages

This project can be published as a website using GitHub Pages. To do this, you can use MkDocs, Jekyll, or Docusaurus.

## Quick Start with MkDocs
1. Install MkDocs:
   ```sh
   pip install mkdocs
   ```
2. Create a `mkdocs.yml` config file and a `docs/` folder.
3. Run `mkdocs serve` to preview locally.
4. Run `mkdocs gh-deploy` to publish.

See [MkDocs documentation](https://www.mkdocs.org/) for more details.
