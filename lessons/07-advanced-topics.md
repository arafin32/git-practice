# Advanced Git Topics

## Submodules
- `git submodule add <repo>` — Add a submodule
- `git submodule update --init` — Initialize submodules

## Bisect
- `git bisect start` — Start binary search for bugs
- `git bisect bad` / `git bisect good` — Mark commits

## Cherry-pick
- `git cherry-pick <commit>` — Apply commit from elsewhere

## Reflog
- `git reflog` — Show reference logs

## Hooks
- `pre-commit`, `pre-push`, etc. — Automate tasks

## Advanced Rebase
- `git rebase -i` — Interactive rebase
