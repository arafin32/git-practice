# Advanced Git

## Stashing
- `git stash` — Stash the changes in a dirty working directory
- `git stash pop` — Remove a single stashed state from the stash list and apply it

## Rewriting History
- `git commit --amend` — Amend the last commit
- `git rebase` — Reapply commits on top of another base tip
- `git reset` — Reset current HEAD to the specified state

## Tags
- `git tag` — List, create, or delete tags
- `git tag v1.0.0` — Create a new tag
- `git push origin v1.0.0` — Push a tag to remote
